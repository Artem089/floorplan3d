# Планировка и дизайн — 2D/3D конструктор

Чисто фронтенд-инструмент для планировки квартиры: расставьте мебель, снесите или перенесите стены, сделайте замеры на 2D-плане, затем одним переключателем переходите в 3D-сцену на Three.js — вид сверху или прогулка от первого лица. Всё приложение — один `index.html`, без сборки, открывается сразу.

## Возможности

**2D-план**
- Масштаб 1:60 / 1:100, единицы — мм
- Библиотека из 60+ предметов мебели и техники (спальня, гостиная, кухня, санузел, техника, кабинет)
- Перетаскивание, поворот (Shift — свободный угол), изменение размеров
- Инструмент замера (Shift — фиксация горизонтали/вертикали)
- Снос не несущих стен; несущие помечены отдельно
- Слои: размеры, названия комнат, мебель, сетка, несущие стены

**3D-сцена**
- Виды: птичий, наклонный, сверху; клик по комнате — перелёт
- Режим прогулки: WASD + мышь на десктопе, виртуальный джойстик на тач-устройствах; клик по двери — открыть/закрыть
- Переключение стен: во всю высоту / срез, слайдер времени суток, ночное освещение
- Детализированная мебель: фасады с фасками и ручками, мягкие изголовья, металлик и керамика с отражениями окружения
- Мебель выбирается и перетаскивается прямо в 3D, синхронно с 2D

**Статистика и работа с планом**
- Автоматический подсчёт площади комнат и жилой площади
- Смена напольного материала по комнатам (ламинат, плитка, мрамор, мозаика, ковролин…) с расчётом стоимости (+5% на подрезку)
- Отмена/повтор; план автоматически сохраняется в браузере
- Сессии: Файл → «Сохранить сессию…» / «Открыть сессию…»
- Экспорт PNG, экспорт/импорт плана в JSON

## Быстрый старт

```bash
git clone <адрес репозитория>
cd <каталог>
python3 -m http.server 8000
# открыть http://localhost:8000
```

Также можно просто открыть `index.html` в браузере.

> Three.js подгружается через CDN jsDelivr — для первого открытия 3D-сцены нужен интернет.

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `T` | 2D / 3D |
| `V` / `M` / `X` | Выбор / Замер / Снос стен |
| `R` / `Shift+R` | Поворот выбранной мебели на 90° |
| `Delete` / `Backspace` | Удалить выбранную мебель |
| `Ctrl/⌘ + D` | Дублировать |
| `Ctrl/⌘ + Z`, `Ctrl/⌘ + Shift + Z` | Отменить, повторить |
| `F` | Вписать в окно |
| `+` / `-` | Приблизить / отдалить |
| `[` / `]` | Показать/скрыть библиотеку и панель |
| `Shift + F` | Полный экран |
| `Esc` | Отменить текущее действие |
| Прогулка: `WASD` / стрелки, `Shift`, `E` | Движение, бег, открыть/закрыть дверь |

## Технологии

- Нативный HTML / CSS / JavaScript, без фреймворков и сборки
- 2D-план рисуется через SVG
- 3D-сцена — [Three.js](https://threejs.org/) r160 (OrbitControls, PointerLockControls, RoundedBoxGeometry, RoomEnvironment, CSS2DRenderer)
- Данные хранятся в `localStorage`
